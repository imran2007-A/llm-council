## Priority Issues

CentreButton is a raycast mesh with no role/tabIndex. Six focusable controls sit inside aria-hidden="true" containers. Zero aria-live/status/alert regions for a multi-minute async run. Fix: real DOM button over the table centre; swap aria-hidden for inert; one polite live region.

**[P1] Tabulate's subtitle contradicts its content.**
"One line each, in the order they were ranked" renders #2, #1, #4, #3. rankOf() is already computed. One sort call.

**[P1] The verdict cannot be kept, and the only forward action deletes it.**
No copy, export, history, or back. Peak-end: every session ends in a deletion.

**[P1] The longest wait is the only unnarrated phase; the question vanishes at submit.**

**[P2] The verdict scrim erases the camera move built for it.**
